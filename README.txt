KOF — одностраничный сайт-визитка (обновлённая версия)

Содержимое:
- index.html — главная страница сайта.
- assets/kof-avatar.png — фирменная аватарка KOF, используемая в шапке сайта.

Как посмотреть:
1. Распакуйте архив целиком.
2. Откройте index.html в браузере.
3. Не отделяйте index.html от папки assets — она содержит логотип.

Как опубликовать:
Загрузите ВСЕ содержимое папки в корень статического хостинга (например, GitHub Pages). В корне должны лежать index.html и папка assets.
